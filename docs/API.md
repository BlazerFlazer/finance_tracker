# FinTrack API Reference

_Generated by `npm run docs:api` from the route source in `server/src/http/routes/` — 137 endpoints across 24 resource files. Do not hand-edit; re-run the script after changing routes._

## Conventions

- Base URL: `/api` (the dev server proxies this from the Vite origin to `http://127.0.0.1:3001`).
- All request/response bodies are JSON; money fields are integer **minor units** (cents), never floats.
- Authenticated requests use an httpOnly session cookie (`ft_session`) set by `/api/auth/login`, `/api/auth/register`, or `/api/auth/demo` — there is no bearer-token mode.
- Every state-changing request (POST/PUT/PATCH/DELETE) must echo the `ft_csrf` cookie value back as an `X-CSRF-Token` header (double-submit CSRF) and originate from an allow-listed Origin.
- A validation failure returns `400` with a machine-readable `{ error: { code, issues } }` shape (`shared/schemas/common.ts`), which the web app maps to a localized message per field.
- "Admin (step-up 2FA required if configured)" means the `ADMIN_REQUIRE_2FA` setting (defaults to on in production) additionally requires the session to have completed 2FA this login.
